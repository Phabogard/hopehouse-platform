# Guide complet du Super Admin

## Utilisateurs et rôles

Créer utilisateur : ouvrir Utilisateurs, cliquer Créer, saisir identité, rôle initial, statut, contact, sécurité, confirmer, audit. Créer Agent/Administrateur/Comptable/Auditeur : sélectionner rôle configuré, vérifier permissions, créer profil associé et wallet si Agent.

Bloquer, débloquer, suspendre, réactiver : ouvrir fiche utilisateur, choisir action, saisir justification, confirmer 2FA si requis, notifier, auditer. Réinitialiser mot de passe, PIN ou code temporaire : choisir type, générer ou invalider, notifier selon canal, auditer. Modifier rôles/permissions : écran Rôles, ajouter/retirer, prévisualiser impacts, confirmer, audit avant/après.

## Catalogues, wallets et commissions

Gérer catalogues : créer, modifier, activer, désactiver, archiver, importer/exporter. Gérer wallets : consulter soldes, transactions, réservations, reçus, corrections. Gérer commissions : règles par service, rôle, agent, période, pourcentage, fixe, plafonds.

## Promotions, QR, stocks et accessoires

Gérer promotions : règles, période, cible, plafonds, cumul. Gérer QR Codes : consulter statuts, révoquer temporaires, auditer scans. Gérer stocks : stock central, mouvements, achat Agent, stock Agent, boutique Agent. Accessoires : produit, prix achat, prix vente conseillé, disponibilité.

## Transactions, historique argent et fraude

Suivre toutes les transactions via recherche par utilisateur, wallet, QR, reçu, commande, appareil, période ou devise. Retrouver l'historique complet d'un argent : origine, débits, crédits, réservations, commissions, corrections, annulations, reçus. Détecter fraude : doublons, appareils suspects, QR réutilisés, annulations anormales, parcours circulaires, volumes atypiques.

## Annulation et récupération

Une transaction peut être annulée automatiquement pendant le délai configuré de 5 minutes par défaut si le statut le permet. Après délai, le Super Admin peut effectuer une annulation exceptionnelle avec justification, 2FA, correction wallet, notification et audit complet.

## Statistiques

Consulter utilisateurs, clients, agents, volumes wallet, commissions, ventes accessoires, stocks, fraudes, connexions, messages, commandes, connecteurs, audits et performances.
