# Annexes

## Concepts obligatoires

Moteur universel, catalogues dynamiques, configuration sans code, connecteurs indépendants, modes manuel/semi-automatique/automatique, audit immuable, historique complet, notifications, reçus, wallets multi-devise, marketplace accessoires, messagerie, QR Codes, sécurité, fidélité, parrainage, promotions, bonus.

## Écarts connus avec le MVP actuel

Le code actuel utilise acteurs de démonstration, RBAC statique, données in-memory, pas de wallet, pas de moteur universel, pas de connecteurs, pas de messagerie, pas de QR, pas de marketplace et pas de persistence PostgreSQL. Ces écarts sont transitoires et ne doivent pas être aggravés.

## Rappel de fusion

Aucune Pull Request ne peut être fusionnée si elle n'est pas conforme à l'architecture officielle, si les tests ne sont pas verts ou si la documentation n'est pas mise à jour.

## Statut normatif

Ce document appartient au corpus officiel Hope House Platform. Il est obligatoire pour toute analyse, conception, développement, test, revue et fusion.

## Garde-fous permanents

Moteur universel, configuration dynamique, wallets numériques, RBAC configurable, connecteurs indépendants, audit complet et compatibilité ascendante sont obligatoires.
